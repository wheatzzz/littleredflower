LRFC PORTAL (The Little Red Flower Club)
Open index.html in Chrome or Edge. Click "Connect the flower" once and pick the ESP32 port.
Keys: P = place petal, R = remove petal, D = debug box.

NAMING
  folders  : css/ js/ lib/ data/ fonts/ img/        (one folder per file type)
  css      : portal.css
  js       : portal-config.js (settings)  portal-flower.js (3D)  portal-gate.js (sequence + USB)
  data     : flower-model.js (made from flower.obj; ask to regenerate if the model changes)
  lib      : three.min.js (3D library, kept here so it works offline)
  img      : logo-main.png  flower-gap.png  petal-loose.png
  fonts    : little-red-flower.ttf
